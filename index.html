Preguntas Frecuentes

¿Mis diseños se suben a algún servidor?
No. Todo el procesamiento se realiza en la memoria de tu computadora. Ninguna imagen ni dato sale de tu equipo.
¿Qué formatos de archivo soporta?
Soporta PNG, JPG, JPEG, WebP, SVG, AVIF, GIF y BMP. Filtra automáticamente carpetas vacías y archivos innecesarios.
¿Qué pasa si dos imágenes se llaman igual?
El sistema tiene detección anti-colisión: renombra automáticamente los duplicados (ejemplo: diseño_1.png) para que nunca se sobrescriba ni se pierda una pantalla.
¿Es compatible con Windows y Mac?
Sí. Funciona en Windows (con lanzador directo .bat incluido), macOS y Linux a través de cualquier navegador moderno (Chrome, Edge, Safari, Firefox).
