## 🛑 El Problema con Google Stitch AI
Cuando descargas tus proyectos desde Google Stitch, la plataforma crea una jerarquía profunda de subcarpetas para cada pantalla:
```
stitch_export/
  └── screens/
      └── home_view/
          └── desktop/
              └── mockup.png
      └── profile_view/
          └── desktop/
              └── mockup.png  <-- ¡Mismo nombre!
```
Tener que abrir y cerrar decenas de carpetas a mano para extraer tus diseños destruye tu productividad.

---

## ✨ La Solución: Stitch Image Extractor PRO
- **Aplanado Recursivo:** Encuentra todas las imágenes (`.png`, `.jpg`, `.webp`, `.svg`, etc.) sin importar qué tan profundo estén escondidas.
- **Galería Visual de Miniaturas:** Inspecciona dimensiones reales (`1920×1080`), peso de archivo y vista previa antes de extraer.
- **Protección Anti-Sobrescritura:** Si dos archivos se llaman igual en distintas carpetas, la aplicación los renombra automáticamente (`diseño_1.png`).
- **100% Privado y Offline:** Todo se ejecuta en la memoria local de tu ordenador. Ningún archivo se transmite a la nube.
- **Exportación Flexible:** Descarga pantalla por pantalla o genera un archivo ZIP 100% plano sin subcarpetas.
